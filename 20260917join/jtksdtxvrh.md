# 北医三院试管移植囊胚是否盲移别还不造？内附试管周期！

目前北医三院做试管移植囊胚大多都是盲移的，因为该院医生经验丰富，对于女性子宫位置、宫颈深度等稔熟于心，即使是盲移试管婴儿成功率也不低，所以大家不用太担心，医生既然敢盲移就肯定是对移植位置有把握的。且本身胚胎移植位置就不用特别精准，因为它还需要在女性体内游离一段时间才会着床，只要保证其在宫腔靠中间位置即可。
北医三院试管移植是不是盲移
据了解，北医三院试管移植是盲移的，而之所以这么操作，主要是因为该院试管技术过硬，基本不会出错，成功率可以达到60%左右。大部分医生在做试管婴儿移植手术的时候还是会采用超声下引导移植，但部分经验丰富、大咖级的生殖专家即使在盲移的情况下也能将胚胎放置在最佳的位置。

若患者不愿意采用盲移这种方式，担心试管成功率，那么可以自己和主治医生提前说，让他们采用超声下引导移植，医生们一般都是会尊重患者选择的，所以患者不用太担心。
Tips:
另外，胚胎移植后，它会在女性宫腔内自由活动，不会停留在一个位置。一般胚胎会在5-7天左右选择合适的位置着床，我们所要做的就是保持平和的心态，从而帮助胚胎着床。
2024北医三院试管移植流程
在北医三院做试管婴儿胚胎移植手术用时很短，一般整个流程仅需5-10分钟左右，疼痛感较小。但是这短短的几分钟里，讲究的事情可真不少，具体如下：

1、憋尿

做移植手术前，患者需要保证膀胱充盈，胚胎移植前憋尿很重要。适量充盈的膀胱对移植有重要的用处，有助于腹部B超引导导管的进入子宫腔的最佳位置。

2、宫颈清洗

为了保证胚胎移植手术顺利进行，生殖医生在正式移植前，会先在B超监测下，置入阴窥镜以后，对女性阴道以及宫颈进行清洗避免手术过程中感染。

3、移植手术

医生将移植内管置入已放好的外导管内，B超下清晰可见导管进入到子宫腔内膜最厚的部位，然后医生推进注射器，将胚胎缓慢注入子宫腔里，停留约30秒，从B超上看见“小白点”从导管里滑入宫腔。

4、B超检查

移植手术完成后，生殖医生会取出内管和外管，并送回实验室检查是否有残留，如果没有环胎残留，客户需要及时排尿或用导尿管将尿导出，如果术后B超检查无任何异常情况，可以平卧休息半小时后自行离开医院。
