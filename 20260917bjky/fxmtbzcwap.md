# 【省医药事】科学补钙，你做对了吗？

> 更新时间：2026-09-17 (UTC+8)

众所周知，钙是维持机体健康的重要元素。在人生各个阶段都需要摄入充足的钙以保证骨骼的健康，维护神经与肌肉的正常活动，促进体内各种酶的活性和参与血液凝固的生理过程等。

缺乏钙元素必然会引起一系列疾病，如儿童佝偻病、中老年人骨质疏松症等。

**01 ****如何科学补钙呢**

钙并不是补的越多越好，科学补钙需适量。人体对钙吸收随生命阶段的不同而异，随年龄的增加吸收率减少，成人大约20%。过量补钙会引起血钙过高、伤肾及伤胃，严重者可诱发高钙血症、免疫系统紊乱等。根据《中国居民膳食营养素参考摄入量》，人体各阶段每天所需钙摄入量是：

**02 ****如何选择合适的钙补充剂**

当食物不足以满足机体钙的需求时，如何选择合适的钙补充剂呢？市面上的钙剂分为无机钙、有机钙、活性钙以及新型钙，最常见的是无机钙和有机钙。无机钙中碳酸钙是口服钙制剂的首选。

然而光补充钙剂是不够的，维生素D可以促进钙的肠道吸收，维生素K可以促进钙的沉淀和骨形成，是补钙的黄金搭档。

补充维生素D最简单的方式是接受阳光照射，再配合适当运动；维生素K在深绿色蔬菜及豆油、菜籽油中含量较高；也可以直接服用复合钙剂。

**03 ****钙剂的服用有什么注意事项**

1. 个体是否需要服用钙剂或联合维生素D、维生素K，需要经过医生评估，选择何种钙剂也应咨询专业医生或药师。

2. 高钙血症或高钙尿症患者避免使用钙剂。对某类钙剂过敏者禁用某类钙剂。心、肾功能不全者，过敏体质者慎用。

3. 钙剂一般随餐或是餐后服用。人体在晚间12点以后至凌晨血钙最低，这时钙剂的吸收和利用率最高。因此，晚餐后服用钙剂最佳。

4. 碳酸饮料、浓茶、咖啡、高盐饮食等饮食习惯会影响钙的吸收；一些蔬菜，如菠菜、竹笋、蕨菜等含有的草酸会与钙结合成人体不易吸收的草酸钙而降低钙的吸收率，应避免同食或者将这些蔬菜提前焯水处理。
